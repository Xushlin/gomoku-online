## 1. 先确认出牌用不用第四种载荷

- [x] 1.1 `Move.Text` 上限 64 字符;一手最多 20 张。一张牌一个字符 → **现有文本载荷就装得下**。

## 7. 两处我自己错了

### 7.1 `WingsAreLegal` 是死代码

我在飞机分支里写了一个守卫执行「翅膀不能拆炸弹」,还专门加了测试去碰它。把守卫改坏 ——
**测试照样绿**。原因:含恰好一个四张的手牌一定先走到四带二分支并在那里被拒,**到不了**飞机分支。

守卫已删。规则的实际执行点(四带二分支末尾的 `return null`)写上了注释,并且验证过它承重:
去掉那个早返,一条测试变红。

> 一个看起来承重的守卫,和一个真的承重的守卫,只有在被改坏的时候才分得出来。

而我第一次为它加的那条测试(4 组三张 + 一个炸弹当翅膀,16 张)本身是对的 —— 它现在钉的是
真正的那个执行点。

### 7.2 我对 seed 0 的后果写错了

原注释:状态 0 会让洗牌"退化成永远不洗"。**不对。** 状态恒为 0 时每次的交换目标都是 0 号位 ——
牌确实动了,54 张也还各一次。真正的后果是**熵全丢**:任何落到零状态的种子发出同一副牌。

所以我原来那条断言("第一手不等于牌堆前 17 张")在守卫被改坏之后照样绿。现在钉精确的那条:
`FromSeed(0)` 必须与直接给出替代常数的种子发出同一副牌,且不等于 `FromSeed(1)`。
