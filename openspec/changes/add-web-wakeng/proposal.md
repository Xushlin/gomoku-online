# add-web-wakeng

## Why

挖坑的规则、按座位可见性、超时兜底都在服务端跑通了(`add-wakeng`,真 SignalR 上打过牌),
而它**没有界面**。这一步给它界面,和 `add-doudizhu` → `add-web-doudizhu` 之间是同一个状态。

## 逐件问「共享的是事实,还是形状」

这是 `hoist-card-model` 那把尺子的第二次使用,而这次要量的是**界面**。判据不变:
**按「是不是同一件事」分,不按「代码长得像不像」分。**

| 现在的位置 | 判定 | 理由 |
| --- | --- | --- |
| `doudizhu/cards.ts` | **共享** → `games/cards/` | 它是服务端 `Card.Alphabet` 的副本。挖坑用**同一批值**、同一个下标 → 同一个事实。两份副本意味着字母表哪天变了要改两处。 |
| `doudizhu/card-art.ts` | **共享** | 一张 ♥ 就是一张 ♥。 |
| `doudizhu/table-layout.ts` | **共享** | 「三个座位环绕、下家在右」是内核 `(seat+1) % N` 的显示读法,与是哪个棋种无关。 |
| `doudizhu/trick.ts` | **共享** | 它只回答**结构**问题(「从最后一手 `play:` 起到末尾」是当前一轮),里面**一个显示字符串都没有** —— 措辞在模板里。 |
| `doudizhu/card-table/` | **共享 + 参数化** | 见下。 |
| `doudizhu/seat-view.ts` | **各一份** | 两种形状:`landlord`/`baseScore` 对 `digger`/`bid`/`firstBidder`/`firstBidderCard`。与服务端 `WakengMove` 不复用 `DoudizhuMove` 是同一条。 |

**牌桌组件共享而不是复制**,理由是具体的:那 374 行 CSS 里的扇形公式**被 shrink-to-fit 咬过四次**,
而它的不变量由 `check-styles.mjs` 按文件名钉着。复制它就是复制一个已经出过四次错的公式,
**而那是一份真的会分叉的第二真源**。两个游戏的差别是四个数和几个标签 —— 那是**参数**,不是分歧,
与 `NInARowRules(key, rows, cols, winLength)` 让一字棋贡献零行判胜是同一个形状。

于是 room-page 那个 `@if` **不多一支**:两个棋种渲染同一个组件、传不同的配置。

## 配置里有什么(而它为什么恰好是这些)

- `kittySize`:3 / 4。
- `bidLabelKeys`:斗地主「叫 N 分 / 不叫」,挖坑「挖 N 分 / 不挖」。
- `roleLabelKey`:地主 / 挖坑者。
- `showsFirstBidder`:挖坑要在桌上标出首叫者与他亮的那张 ♣(**服务端算的,公开的**);
  斗地主没有这个概念。
- `compareForDisplay`:**手牌的显示顺序**。
- `parseSeatView`:把两种 `seatView` 归一成牌桌要画的那一份视图模型 —— 解析各一份(对),
  绘制只有一份(对)。

## `compareForDisplay` 是一处真缺陷的预防,不是一个配置项凑数

服务端送来的 `myHand` 是 `Card.Encode` 的输出,而那是**编码顺序**(3、4、…、K、A、2)。
斗地主的大小恰好就是这个顺序,所以它按原样渲染是对的。**挖坑是 `3 > 2 > A > … > 4`** ——
按原样渲染会把**最强的那张牌放在最左边**,而第二张是最弱的 4。

**这是同一个巧合第三次咬人**,而前两次都留下了记录:`hoist-card-model` 改掉 `CardRank`
「数值就是大小顺序」那句注释,`add-wakeng` 修掉超时兜底照抄 `HandOf(seat)[0]`。
这一次它在**客户端**,而 `DoudizhuCard.rank` 的文档此刻仍然写着「数值就是大小顺序」——
那句话跟着 `cards.ts` 一起搬,所以它在这里被改对。

## 不做什么

- **牌桌不判任何合法性**,与斗地主逐字相同,而挖坑的理由更硬:牌型识别要认八种、压牌还要
  同型同张数比大小,两者都已经在服务端且是这一局唯一的判据。**唯一不需要规则的那条**——
  「桌上没牌,所以你不能过」—— 照样在客户端判。
- **没有 AI**,所以没有人机入口。`GET /api/games` 的 `supportsAi: false` 已经在管这件事。
- **没有排行榜入口**:`isRated: false`,而目录页按它渲染,不需要新代码。

## 验收

- `/g/wakeng/lobby` 能进、能建房、坐满三人开局;`/rooms/:id` 画出牌桌。
- **在浏览器里真叫一次分、真出一次牌**,并核对手牌张数与桌面变化 ——
  与 `add-web-doudizhu` 同一条标准。
- **375 px 带满屏内容**:20 张手牌 + 两家牌背 + 桌上一手,页面级与逐元素溢出都是 0。
  空手牌上这条检查是白过的。
- **手牌顺序**:一条断言钉住挖坑的手牌按 `3 > 2 > A > … > 4` 排,而斗地主**不受影响**。
  那条断言 MUST 用一手**含 3 或 2** 的牌 —— 否则两种排序给出同一个结果。
- 变异:配置里的 `compareForDisplay` 换成斗地主那份 MUST 红;`kittySize` 写死 3 MUST 红。
