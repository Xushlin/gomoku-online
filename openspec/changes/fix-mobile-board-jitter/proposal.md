# 手机端棋盘每落一子跳一下

## 症状

真机上报:**五子棋和象棋落子时界面闪动。**

## 原因,以及它为什么和棋种无关

`add-mobile-game-actions` 在棋盘下方放了一行「为什么现在不能催」的说明,而它携带的理由是
**「当前是你的回合」** —— 轮到你时为真,轮到对手时为空。于是这一行**每落一子出现/消失一次**;
棋盘在 `Expanded` 里居中,列一重排,棋盘就跟着变。

**量出来的**(`test/board_stability_test.dart`,800×600 画布):轮到我 `408×408`,对手回合
`428×428` —— 每一手棋变化 **20 px**。

「两个棋种都有」本身就是线索:它跟任何一个 renderer 都没关系。

同一类还有第二处,只是更少见:被拒绝的走子会在棋盘**上方**插入一行错误文案,棋盘因此
408 → 364(**44 px**)。

## 做什么

- 那行理由**始终占位**(`Visibility(maintainSize: true)`),有理由时才显示文字。
  **不是删掉它** —— `add-mobile-game-actions` 要求禁用时必须说明原因。
- 错误文案改为**叠在棋盘上方**(`Stack` + `Positioned`),不再占布局。
  **不改成 SnackBar**:那东西会自己消失,而 `integration_test/xiangqi_test.dart` 断言的是
  那句拒绝**在屏幕上**。

## 这块屏幕此前没有任何单测

`GameView` 从来没有被单独挂起来过 —— 只有集成测试整个 app 挂过,而它们从不比较一次回合
变化前后的矩形。这一笔补上了那条测试,并且**它先红后绿**。
