# add-mobile-shell

Flutter 手机端的第一刀:**外壳 + 登录 + 一个棋种(五子棋),跑在 Android 上。**

## Why

用户要的,而这个决定的代价我提过两次,所以这里把它记成**已经做出的选择**而不是重新论证:

| | |
| --- | --- |
| 要重写的 UI | **66 个组件 / 53 个模板 / 约 18,700 行** |
| 要重做的 | 4 主题 × 明暗、3 套棋盘皮肤(43 个变量)、音效包、第二个 SignalR 客户端 |
| **第 11 个游戏** | **两份实现,永远** |

而 Flutter 给的、Electron **永远给不了**的东西只有一样:**iOS 与 Google Play**。这一条是整件事唯一的理由,所以它值不值全看那个诉求有多真。

## 这一刀切在哪里,以及为什么不是「移植」

**不做十个游戏。** 第一个变更是一条**垂直切片**:外壳 + 登录 + 五子棋。

理由是把两个**真正不确定**的东西提前证伪,而不是留到第九个游戏:

1. **JWT + 刷新流在 Dart 里跑不跑得通** —— token 轮换、401 重试、refresh token 存哪。
2. **`signalr_netcore` 能不能跟我们的 hub 说话。** 它是社区包,1.4.4,**最近一次发布 2025-09-05**;我们的 hub 走查询串 JWT(`?access_token=`)+ JSON 协议 + 具名方法。

**第 2 条是这个提案最大的风险,而它不是「难」,是「可能根本不通」。** 不通的话手机端就得换传输方案(自己写 WebSocket 协议层,或者给 hub 加一条 REST 落子路径),而那是一个比 UI 重写更大的决定。**所以它必须在第一刀里就被回答**,不能等到 UI 铺完。

选五子棋而不是猜成语,正是因为猜成语只走 REST —— 它验不到上面第 2 条。

## 两样东西 MUST NOT 重抄一遍

- **i18n。** `frontend-web/public/i18n/{zh-CN,en}.json` 是 **547 个键 × 2 个 locale**。手机端 MUST 读**同一份产物**,MUST NOT 建第二套翻译。两套翻译的漂移表现是「同一句话两个端不一样」,而没有任何东西会报告它。
- **API 契约。** DTO 形状 MUST 对着后端的真源,而不是照着 web 客户端的 TS 手抄一遍 —— 抄的那份会在下一次契约变更时静静过期(这个仓库刚为 `GameReplayDto` 的座位表付过一次账)。

## 验证:Android 模拟器,不是「能编译」

工具链量过了:Flutter 3.48 stable、Dart 3.13.1、Android SDK 36.1、**Pixel 7 API 35 / 36 两台模拟器可用**。

所以验收是**在模拟器里真登录、真下一步棋**,而不是 `flutter build` 成功。

**一个具体的坑写在这里,免得当成 bug 查:** 模拟器里的 `localhost` 是模拟器自己,宿主机的回环是 **`10.0.2.2`**。后端跑在宿主的 5145,所以 app 的默认地址在 Android 上必须是 `http://10.0.2.2:5145` —— 这与桌面壳的 `localhost:5145` 是同一个「宿主给地址」的问题,只是答案不同。

## What changes

- 新目录 `frontend-mobile/`(Flutter 工程,与 `frontend-web/` / `frontend-desktop/` 平级)。
- 外壳:Material 3、主题(浅/深)、locale 切换,读 web 端那份 i18n JSON。
- 登录 / 注册 / 刷新,token 存 `flutter_secure_storage`。
- 大厅(房间列表 + 建房)与**五子棋**一个棋种:棋盘、落子、实时同步。
- 后端 **零改动**(CORS 不涉及原生客户端;那是浏览器的概念)。

## Non-goals

- **另外九个棋种。** 一个一个来,与 web 端当初同一条路。
- **iOS 构建。** 需要 macOS,这台机器上做不了 —— 而且这条要说清:**Flutter 的全部理由是 iOS + Google Play,而 iOS 那一半在这里验不了。**
- **离线。** 与三个内核的授权模型冲突,理由与桌面壳那次一字不改。
- **音效包与棋盘皮肤。** 第一刀不做,它们是 CSS 概念,Flutter 侧要重新设计。
- **上架。** 要开发者账号与签名身份。
