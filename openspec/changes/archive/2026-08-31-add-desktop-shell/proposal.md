# add-desktop-shell

Electron 桌面壳:双击就开、有图标、没有地址栏。**十个游戏一个不改地带上。**

## Why

用户要的。而 `add-api-base-url` 已经把唯一那块拦路石搬开了 —— 客户端现在能指向一台远程服务器。

**这一步的性价比是量出来的**:Angular 产物 `dist/gewu-web/browser/` 原样装进壳里,66 个组件、547×2 个 i18n 键、4 主题 × 明暗、3 套棋盘皮肤、1053 条测试**全部复用**,而第 11 个游戏仍然只写一份。

## 三个决定,而第一个是全部难点

### D1:自定义 `app://` 协议 —— 不是 `file://`,也不改哈希路由

`index.html` 里写着 `<base href="/" />`。在 `file://` 下 `/` 解析到**文件系统根**,于是每一个 chunk 都 404 —— 而症状是一个白屏,控制台里一串找不到的文件,看起来像构建坏了。

三条出路,前两条要拒:

1. **`file://` + 改哈希路由。** 拒:路由模式是 Web 端共享的,改它就改了浏览器里的 URL 形状。`add-api-base-url` 刚立下「Web 端行为一个字节不变」,不该在下一个变更里自己破例。
2. **壳里起一个本地 HTTP 服务器。** 拒:多一个会冲突的端口、多一个要管的生命周期,而它换来的东西 `app://` 免费给。
3. **自定义协议 `app://`。** 取这条。

`app://` 给的是一个**真正的 origin**,而那不只是整洁:`localStorage`(refresh token 就在里面)有稳定的分区、CSP 写得出、路径路由原样工作、`<base href="/">` 一个字不用改。用 Electron 的 `protocol.handle()`。

### D2:路径穿越是本变更唯一真正的安全面,而它 MUST 是一个可单测的纯函数

`app://x/../../../../Windows/System32/config/SAM` 必须解析不出 dist 目录。

把「URL → 磁盘路径」抽成纯函数,理由是**它是这里唯一能被恶意输入触碰的东西**,而它恰好也是最容易单测的东西 —— 不需要启动 Electron 就能钉住。

### D3:服务器地址从哪来

preload 用 `contextBridge` 暴露一个只读值,`API_BASE_URL` 的 factory 读它。

**这样不需要第二份 Angular 构建** —— 同一份产物,浏览器里读不到那个全局(于是仍然是空字符串、仍然同源),桌面壳里读得到。而这个机制对将来的手机壳、以及「静态站点 + 独立 API 域名」的自托管部署同样适用。

地址本身 v1 从**可执行文件旁边的配置**读,缺省 `http://localhost:5145`(本地开发那台)。设置页是后续的事。

## 安全姿态,写下来是因为默认值不安全

- `contextIsolation: true`、`nodeIntegration: false`、`sandbox: true` —— 渲染进程拿不到 Node。
- preload **只暴露一个只读字符串**,不暴露任何函数。
- CSP 由协议响应头给。
- `setWindowOpenHandler` 与 `will-navigate` 拦住一切外部导航 —— 一个游戏厅没有任何理由在自己的窗口里打开外站。

## What changes

- 新目录 `frontend-desktop/`(自己的 npm 项目,与 `frontend-web/` 平级 —— 仓库没有根 package.json,不新造 workspace)。
- main / preload / 协议处理 / 打包配置。
- `frontend-web` 一处:`API_BASE_URL` 的 factory 读那个宿主全局。默认仍是 `''`。

## Non-goals —— 每一条都说清为什么

- **自动更新。** 需要一个更新服务器与签名身份,而两者都还不存在。**触发条件:第一次真的要发给别人用。**
- **Microsoft Store 上架。** 打包配置可以先写好,但**提交需要发布者账号与代码签名证书,那是只有你能提供的东西** —— 我不会假装做得了。
- **离线。** 与平台的授权模型相反(答案永不出服务端、华容道重放每一步、登录要 API),那是动内核的独立决定。
- **手机端。** Electron 上不了 iOS / Google Play,这条 `add-api-base-url` 里已经写明。
- **不动 Web 端的行为。** 同一份产物,浏览器里逐字节不变。

## 验收

- 协议解析与穿越拒绝:纯函数单测,**包含一条真的穿越尝试**。
- 宿主全局在场 / 不在场两种情况下 `API_BASE_URL` 的取值 —— **两条都要**,少了后一条,一个「永远返回默认」的实现也能通过。
- **真的把窗口开起来**:登录一次、进一个游戏、确认实时连接活着。壳的价值全在「它真的能跑」,而那件事没有单测替代品。
