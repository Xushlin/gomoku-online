# add-game-action-bar

棋盘底下多一条操作条,而「轮到谁、还剩多少秒、我能做什么」从右侧栏搬进去。

## Why

**量出来的:** 375 px 宽的房间页,棋盘是 311×311、顶在 `top=100`。而

| | y | 高 |
| --- | --- | --- |
| 「剩余 0:47」 | **638** | 17 |
| 催一下 / 认输 / 离开 | **675 / 713 / 751** | 各 **30** |

搬之后,同一次测量:操作条顶在 **427**,倒计时 **440**(高 36),三个按钮都在 **488**、**各 44 px 高**。

(量法:真浏览器读 `getBoundingClientRect`,CSS 是构建产物。但**视口是手工按住的** —— pane 报告「已设为 375×812」,页面始终报 `innerWidth 981`,所以按 375 px 会发生的两件事手动施加:375 px 的容器宽 + 不匹配 `md:`/`sm:`/`lg:`。

**而第一版量错了一次,值得记:** 搬前搬后各用一个探针文件,两边报出的棋盘宽**不一样**(295 对 311)—— 因为其中一份留着 `<main>` 上的 `sm:px-6 lg:px-8`,而那两个变体在**视口 981** 下是匹配的,即使容器只有 375。上面这些数出自**一个文件、一次运行、两半并排**。两个环境里量出来的数不是一个对比。)

一台 375×812 的手机减掉浏览器自己的界面,可用高度大约 **700 px**。对着上面那张表:倒计时下沿 655 —— **贴在屏幕最下沿**;催一下下沿 705 —— **压线**;**认输 713、离开 751 在屏幕外**。也就是说要认输得先滚过整块棋盘。iPhone SE 那一档可用高度约 550,四样全部在屏幕外。

搬之后最下面那个按钮的下沿是 **532**。

第二件事:三个按钮**各 30 px 高**。WCAG 2.2 的 AA 底线(SC 2.5.8)是 24×24,所以它们**合规**;而 SC 2.5.5(AAA)与各家移动端指南要的是 44。它们看起来也不像主操作 —— `cell`(有边、无填充)+ `text-xs`,和棋盘格是同一个角色。

## What Changes

- 新增 `app-action-bar`,渲染在**棋盘那一列的最后** —— 于是手机上它紧贴棋盘下沿,桌面上它在棋盘正下方(QQ 游戏就是这个位置)。
- **搬,不是抄。** 从侧栏搬走三样:回合指示、倒计时、玩家按钮组。侧栏留下「谁在这儿」:房间名、房主、座位名单、状态徽章、观战人数。
  - 分界是**「现在怎么样 + 我能做什么」对「这里有谁」**,而不是「重要的放下面」。
- 按钮 `min-h-11`(44 px)+ `text-sm font-semibold`,横排,375 px 下换行成两行。
- **不加角色、不加 token。** 用既有的 `panel` —— 它自带渐变、硬边(牌的厚度)与 `--shadow-raised`,这正是「厚重」在这套 token 里的说法。
- **零新增 i18n 键**:`game.turn.*` / `game.actions.*` 都已存在。

## 为什么不做成吸底

`position: sticky bottom-0` 是 QQ 游戏的做法,而在这里它买不到东西:**把操作条放在棋盘下沿之后,它已经在第一屏了**(棋盘底 411 + 间距 16 = 427,量到的就是 427)。而吸底要付三样:iOS 的 `env(safe-area-inset-bottom)`、盖住内容、以及**斗地主 / 挖坑的牌桌自己有一排出牌按钮** —— 两条操作条上下叠着,「哪个是出牌」要人想一下。

**所以这一版的判据是 y 坐标,不是位置属性。** 量到「在第一屏」就够了;吸底留到有一个够不着的东西为止。

## 牌桌那一排不动

`card-table` 的出牌 / 不要 / 提示是**牌桌的一部分**(它贴着你的手牌,而选牌状态就在那里),不搬。操作条拿的是房间级动作:催、认输、离开。**两排按钮职责不同,而这一条差别写进 spec** —— 否则下一个人会把它们合并,然后发现出牌按钮离手牌 400 px 远。

## 宽度取列宽,不去对齐棋盘

棋盘是 `max-width: 480px` 居中,象棋盘与牌桌各有自己的宽。操作条 `w-full` 占满棋盘那一列 —— 与其挑一个棋种的宽度去对齐,不如占满,读起来是「桌沿」。

## 顺序上的一件事

底部操作条把主按钮做大做显眼,而 `fix-primary-label-contrast` 量到 25 个主按钮的字色在 qq-game 暗色下是 1.58:1。**先修那一条,再做这一条** —— 否则这次改动做的事是把一个读不出来的标签放大。
